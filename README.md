# แอปรายการสิ่งที่ต้องทำ (Thai Todo)

React + Vite + Tailwind CSS + lucide-react

## เริ่มใช้งาน
```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm run build    # สร้างไฟล์ production ใน dist/
```

ข้อมูลทั้งหมดเก็บใน React state เท่านั้น (ไม่มี localStorage) รีเฟรชหน้าแล้วข้อมูลจะรีเซ็ต
